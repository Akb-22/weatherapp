# Weather Forecast App 🌦️

A weather forecast web application that provides current weather information and forecast details based on the selected location.

## 🚀 Features

- 🌤️ Search weather by location
- 📅 View weather forecast
- 🌡️ Display temperature and weather conditions
- 💨 Show weather-related details
- 📱 Simple and responsive user interface
- 🔗 Fetches weather data using a weather API

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- REST API
- Open-Meteo API
